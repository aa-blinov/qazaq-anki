GitHub

Изучайте казахский язык по методу интервального повторения Anki, на своём сервере.

Карточки с алгоритмом SM-2: вы оцениваете, насколько вспомнили слово, и оно возвращается именно тогда, когда начинает забываться. Пять уровней CEFR, озвучка каждого слова двумя голосами, статистика по темам. Всё приложение ставится у вас на машине и не отправляет никуда ни одного байта ваших данных.

Установка на GitHub

MIT. Три контейнера на Docker или два процесса на Node 22. 3 996 слов, уровни от A1 до C1. Сколько слов в каждом

Так выглядит карточка

Слово, транскрипция, а после переворота перевод и четыре оценки. Настоящие данные из колоды B1.

Пять уровней, пять колод

CEFR служит осью, вокруг которой построены и словарь, и статистика: освоенное считается по уровням, а не «по теме недели».

Что поднимается у вас на машине

Приложение
React и TypeScript, собранные в статические файлы и отданные nginx. Учётные записи и прогресс лежат в вашей базе SQLite.
Аккаунты
Node и Express, пароли хранятся в виде bcrypt-хешей. У каждого пользователя свой остров данных.
Озвучка
Piper: kk_KZ-issai-high для казахского и ru_RU-denis-medium для русского. 7 473 готовых FLAC-файла, 168 МБ.
Резервные копии
Ежечасный снимок SQLite по расписанию. В проде стоит Caddy с автоматическим TLS.

Почему на этой странице нет самой программы

Эта страница, статический файл на GitHub Pages, честно показывает только то, что можно показать без сервера. Само приложение живёт у вас: аккаунты и прогресс создаются на вашей машине, поэтому по ссылке их отдать нельзя. Так и должно быть.

Söz распространяется по лицензии MIT. Телеметрии нет. Версия 0.1.0.
