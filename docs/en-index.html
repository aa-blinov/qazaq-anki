Learn Kazakh with Anki-style spaced repetition, on your own server.

Cards running the SM-2 algorithm: you rate how well you recalled a word, and it returns just as you start to forget it. Five CEFR levels, audio for every word in two voices, and progress broken down by topic. The whole app runs on your own machine and sends not one byte of your data anywhere.

What comes up on your machine

The app
React and TypeScript, built to static files and served by nginx. Accounts and progress live in your own SQLite file.
Accounts
Node and Express, passwords stored as bcrypt hashes. One username is one data island.
Audio
Piper: kk_KZ-issai-high for Kazakh and ru_RU-denis-medium for Russian. 7,473 pre-rendered FLAC clips, 168 MB in total.
Backups
An hourly SQLite snapshot on a schedule. In production, Caddy with automatic TLS.

Why the app itself is not on this page

This page is a static file on GitHub Pages, and it shows only what can honestly be shown without a server. The app itself lives on your machine: accounts and progress are created where you run it, so there is nothing for a link to hand over, and there should not be.
